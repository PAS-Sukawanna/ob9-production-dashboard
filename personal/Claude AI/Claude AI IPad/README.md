# Claude AI IPad — Dividend Portfolio Dashboard

แดชบอร์ดพอร์ตหุ้น SET เน้นการเก็บกินปันผลรายปีและหาจังหวะ take profit
ออกแบบให้ใช้งานสะดวกบน iPad (แตะง่าย, เพิ่มลง Home Screen ได้, ทำงานออฟไลน์)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | รายละเอียด |
|------|-----------|
| `stock_portfolio_dashboard.html` | แดชบอร์ดหลัก (ไฟล์เดียวจบ ฝัง Chart.js ไว้ในตัว เปิดในเบราว์เซอร์ได้เลย) |
| `source_portfolio_screenshot_1.png` | รูปพอร์ตต้นทางจากแอป broker (หน้าที่ 1) |
| `source_portfolio_screenshot_2.png` | รูปพอร์ตต้นทางจากแอป broker (หน้าที่ 2) |
| `SETHD_JITTA_reference.xlsx` | ไฟล์อ้างอิงหุ้นปันผล SETHD / JITTA (P/E, P/BV, %ปันผล, กลุ่มธุรกิจ) |

## วิธีใช้บน iPad

1. เปิด `stock_portfolio_dashboard.html` ใน Safari
2. กดปุ่มแชร์ → **Add to Home Screen** เพื่อเปิดแบบเต็มจอเหมือนแอป (ชื่อ "พอร์ตปันผล")
3. ข้อมูลถูกบันทึกในเครื่อง (localStorage) — กด **Export JSON** เพื่อสำรอง/ย้ายเครื่อง

## ฟีเจอร์

- **ภาพรวมพอร์ต** — Vision card (มูลค่าตลาด, กำไร/ขาดทุน, ปันผลรับต่อปี, Yield on Cost, แถบความคืบหน้าต่อเป้าปันผล), กราฟสัดส่วนตามกลุ่มธุรกิจ, กราฟ %กำไรรายตัวสำหรับดูจังหวะ take profit
- **รายกลุ่มธุรกิจ** — จัดกลุ่มหุ้น 8 กลุ่ม พร้อม subtotal และสัญญาณ (สะสมเพิ่ม / ถือปันผล / พิจารณา TP / ติดตาม)
- **จัดการหุ้น / อัปเดต** — เพิ่ม/ลบ/แก้ไขหุ้น, อัปเดตจากรูป capture โดยวางข้อความจากแอป broker, ตั้งเงินสด/เป้าปันผล, บันทึกโน้ตกลยุทธ์, Export/Import JSON

## หมายเหตุ

ตัวเลขปันผลต่อหุ้นเป็นค่าประมาณจากปีล่าสุด (ไฟล์อ้างอิง) — แก้ไขได้ในตาราง
ควรตรวจสอบกับประกาศจ่ายปันผลจริงของบริษัทก่อนตัดสินใจลงทุน
