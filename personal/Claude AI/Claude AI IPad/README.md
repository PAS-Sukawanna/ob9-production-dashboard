# Claude AI IPad — Dividend Portfolio Dashboard

แดชบอร์ดพอร์ตหุ้น SET เน้นการเก็บกินปันผลรายปีและหาจังหวะ take profit
ออกแบบให้ใช้งานสะดวกบน iPad (แตะง่าย, เพิ่มลง Home Screen ได้, ทำงานออฟไลน์)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | รายละเอียด |
|------|-----------|
| `stock_portfolio_dashboard.html` | แดชบอร์ดหลัก (ไฟล์เดียวจบ ฝัง Chart.js ไว้ในตัว เปิดในเบราว์เซอร์ได้เลย) |
| `manifest.json`, `sw.js`, `icon-*.png` | ไฟล์ PWA (ติดตั้งเป็นแอป + ทำงานออฟไลน์) |
| `SETHD_JITTA_reference.xlsx` | ไฟล์อ้างอิงหุ้นปันผล SETHD / JITTA (P/E, P/BV, %ปันผล, กลุ่มธุรกิจ) |

## 🔒 ความเป็นส่วนตัวของข้อมูล

repo นี้เป็นสาธารณะ ดังนั้น **ไฟล์นี้ไม่มีข้อมูลพอร์ตจริง** — ค่าตั้งต้นในโค้ดเป็น
*ข้อมูลตัวอย่าง* เท่านั้น ข้อมูลพอร์ตจริงของผู้ใช้จะถูกเก็บไว้ในเครื่อง (localStorage)
และไฟล์ Export JSON ส่วนตัว ไม่เก็บลงในซอร์สโค้ดสาธารณะ

- โหลดข้อมูลจริง: แท็บ **จัดการหุ้น → Import JSON**
- สำรอง/ย้ายเครื่อง: **Export JSON** เก็บไฟล์ไว้ส่วนตัว
- การจำกัดสิทธิ์เข้าถึงลิงก์: ดู `ACCESS_CLOUDFLARE.md`

## วิธีใช้บน iPad

1. เปิด `stock_portfolio_dashboard.html` (หรือลิงก์ที่โฮสต์ไว้) ใน Safari/Chrome
2. กดปุ่มแชร์/เมนู → **Add to Home Screen** เพื่อเปิดแบบเต็มจอเหมือนแอป
3. โหลดข้อมูลจริงด้วย **Import JSON** ครั้งแรก จากนั้นระบบจำไว้ในเครื่อง

## ฟีเจอร์

- **ภาพรวมพอร์ต** — Vision card, กราฟสัดส่วนตามกลุ่มธุรกิจ, กราฟ %กำไรรายตัว, การ์ดแจ้งเตือนราคาเป้าหมาย, ปุ่มดูรายตัว
- **รายกลุ่มธุรกิจ** — จัดกลุ่มหุ้น 8 กลุ่ม พร้อม subtotal และสัญญาณ (สะสมเพิ่ม / ถือปันผล / พิจารณา TP / ติดตาม)
- **ปฏิทินปันผล** — ประมาณการเงินสดปันผลรายไตรมาส + ตารางรอบจ่ายรายตัว
- **หน้ารายตัว** — ปันผลย้อนหลัง 5 ปี, กราฟราคาย้อนหลัง, เครื่องมือ **Trim ขายทำกำไร vs ถือรอปันผล**
- **จัดการหุ้น / อัปเดต** — เพิ่ม/ลบ/แก้ไข, อัปเดตจาก **รูป capture (OCR)** หรือวางข้อความ, ตั้งราคาเป้าหมาย, Export/Import JSON

## หมายเหตุ

ตัวเลขปันผลต่อหุ้นเป็นค่าประมาณจากปีล่าสุด (ไฟล์อ้างอิง) — แก้ไขได้ในตาราง
ควรตรวจสอบกับประกาศจ่ายปันผลจริงของบริษัทก่อนตัดสินใจลงทุน
