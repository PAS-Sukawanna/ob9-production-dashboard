เชื่อมต่อ Google Sheet
วิธีเตรียม Google Sheet:
1. สร้าง Google Sheet ใหม่ และตั้งชื่อชีตว่า Daily และ Monthly (ดูโครงสร้างคอลัมน์ด้านล่าง)
2. ไปที่ File > Share > Publish to web แล้วเลือก "Entire Document" และกด Publish
3. คัดลอก Sheet ID จาก URL ของ Google Sheet เช่น
https://docs.google.com/spreadsheets/d/SHEET_ID_ตรงนี้/edit
4. วาง Sheet ID ในช่องด้านบน แล้วกด "เชื่อมต่อ & โหลดข้อมูล"
5. การตั้งค่าจะถูกบันทึกไว้ในเบราว์เซอร์ (localStorage) สำหรับครั้งถัดไป
